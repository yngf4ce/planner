# История изменений

Формат: новые записи сверху. Версии — `0.x` до выхода стабильной версии.

## [0.8.0] — 2026-11-01 (бот готов, ждёт настройки)
### Добавлено
- **Бот Noctis AI** — `supabase/functions/bot/index.ts`: текст и голос (ru/uk/en), несколько команд в одном сообщении,
  задачи с датой и временем, повторы, цели месяца, идеи (с расшифровкой голосового), расходы/доходы/переводы,
  отчёты «сколько потратил», «что на сегодня», «баланс»; команды `/today`, `/balance`, `/help`;
  подтверждение финансов кнопками, «Отменить» для сохранённого; защита от повторной обработки и двойного нажатия.
  Покрыт 33 проверками на заглушках Telegram/Groq/базы.
- `supabase/migrations/003_bot.sql` — таблицы `bot_updates`, `bot_pending` (проверено на PostgreSQL 16).
- `SETUP_GUIDE.md` — раздел 6: настройка бота.

## [0.7.0] — 2026-11-01
### Добавлено

  фильтры «Все / Новые / В работе / Архив» со счётчиками, фильтр по тегу, поиск (по тексту, тегам и расшифровке);
  смена статуса нажатием на плашку; «В задачи» — создаёт задачу на сегодня и переводит идею «В работу».
- Поля `source` и `transcript` у идеи — для голосовых идей от бота (этап 6).

### Технически
- IndexedDB версии 5: хранилище `ideas`; синхронизация через тип записи `idea` (правка сервера не нужна).

## [0.6.0] — 2026-11-01
### Добавлено
- **Раздел «Финансы»** (экраны «Финансы» и «Новая операция» из референса):
  - **Обзор**: общий баланс (по валютам, без выдуманного пересчёта курса), изменение за месяц, список балансов,
    диаграмма расходов месяца по категориям, последние операции, кнопка 👁 «скрыть суммы»;
  - **Операции**: по месяцам, фильтры по балансу и категории, итоги расходов/доходов, группировка по дням;
  - **Бюджеты**: лимит на категорию в месяц, общий прогресс, красная подсветка при превышении;
  - **Новая операция** (кнопка «+»): расход / доход / перевод, сумма, баланс, категория, комментарий, дата;
    перевод между разными валютами — с отдельной суммой зачисления;
  - **Балансы**: название, валюта (EUR/USD/UAH), остаток, цвет, архив; правка остатка без изменения истории;
  - **Категории**: 7 базовых расходных + 4 доходных, свои категории с иконкой и цветом, переименование, архив;
    создание своей категории прямо из формы операции.
- Настройка «Основная валюта» (⚙️).
- Нижняя панель как в референсе: Сегодня · Календарь · Месяц · **Финансы** · Ещё. «Дневник» перенесён в «Ещё».
- `supabase/migrations/002_kinds.sql` — сервер принимает любые новые типы записей (финансы, будущие идеи/здоровье).

### Технически
- Суммы — целые числа в центах; разбор ввода без float («15,5», «1 250.00»).
- Остаток баланса вычисляется из операций → не может разойтись с историей.
- id операции создаётся при открытии формы, кнопка блокируется на время сохранения → двойное нажатие не создаёт дубль
  (проверено тестом).
- Базовые категории имеют постоянные id и «нулевую» дату изменения → без дублей между устройствами, ваши переименования всегда приоритетнее.
- IndexedDB версии 4: хранилища `accounts`, `categories`, `txns`, `budgets`.

## [0.5.0] — 2026-11-01 (сервер подготовлен, синхронизация включится после настройки Supabase)
### Добавлено
- `supabase/migrations/001_sync.sql` — таблица `records`, RLS без доступа публичных ключей, функция `sync_push`,
  приватный бакет `photos`. Проверено на PostgreSQL 16: повторный запуск безопасен, старые версии не затирают новые,
  данные пользователей разделены, роль `anon` не имеет доступа.
- `supabase/functions/api/index.ts` — серверная функция: проверка подписи Telegram, белый список ID, CORS, `/sync`, `/photos`, `/health`.
  Покрыта 13 проверками (подделанная/просроченная подпись, чужой ID, мусорные данные и т.д.).
- Синхронизация целей месяца и повторяющихся задач в приложении.
- `SETUP_GUIDE.md` — пошаговая настройка Supabase.

## [0.4.0] — 2026-11-01
### Добавлено
- **Вкладка «Месяц» переделана** (экран «План на месяц» из референса):
  - переключение месяцев «‹ ›», кнопка «Сейчас»;
  - **цели месяца** — без даты, живут только в «Месяце»; отметка выполнения, процент и «N из M»;
  - **цель в числах** (например, 30 откликов): полоска прогресса «8 / 30» и кнопка «+1»;
  - **повторяющиеся задачи**: переключатель «Повторять», дни недели (каждый день / будни / выходные / свои),
    дата начала и окончания (или «без срока»), время, **пауза**, удаление;
  - задачи с датой этого месяца сгруппированы по дням, просроченное за 2 недели.
- Повторяющиеся задачи **сами появляются в «Сегодня»** и в календаре; отметка выполнения — отдельная для каждого дня.
- Повторы учитываются в проценте дня, точках календаря и статистике.

### Исправлено
- Задача без даты, добавленная в «Месяце», больше **не попадает на завтра** — она становится целью месяца.
- Поля даты и времени на iPhone больше не вылезают за границы карточки.

### Технически
- IndexedDB версии 3: новые хранилища `goals` и `rules`. Повторы хранятся правилами (без копий на каждый день),
  отметки — в поле `done` правила по датам. Старые данные не затрагиваются.
- Резервная копия (версия 2) включает цели и повторы; старые копии по-прежнему восстанавливаются.

## [0.3.0] — 2026-11-01
### Добавлено
- **Время у задачи** (необязательно). Задачи на «Сегодня» группируются: «В течение дня», «Утро» (до 12:00), «День» (12–18), «Вечер» (после 18:00).
- Шапка «Сегодня»: приветствие по имени из Telegram, кольцо процента выполнения, быстрый переход «Вчера / Завтра / К сегодня».
- Кнопка «+ Новая задача» под списком.
- **Календарь-месяц** (по умолчанию): крупная сетка, точки состояния дня (в планах / выполнено / частично / не выполнено / важное / дневник), выбор дня показывает его задачи, с которыми можно работать прямо там. Годовой вид сохранён во вкладке «Год»; нажатие на день в году открывает этот месяц.

### Изменено
- Задачи показываются внутри общей карточки с разделителями (во всех разделах).
- Отметка «выполнено» — синяя, как в референсе; переключатели (Месяц/Год, Неделя/Месяц/Год) — с синей активной кнопкой; градиент у полосы прогресса.

### Технически
- Новое поле задачи `time` (`"HH:MM"` или пустая строка). Старые задачи работают без изменений. При переносе задачи время сохраняется.
