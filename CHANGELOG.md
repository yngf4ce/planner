# История изменений

Формат: новые записи сверху. Версии — `0.x` до выхода стабильной версии.

## [0.3.0] — 2026-11-01
### Добавлено
- **Время у задачи** (необязательно). Задачи на «Сегодня» группируются: «В течение дня», «Утро» (до 12:00), «День» (12–18), «Вечер» (после 18:00).
- Шапка «Сегодня»: приветствие по имени из Telegram, кольцо процента выполнения, быстрый переход «Вчера / Завтра / К сегодня».
- Кнопка «+ Новая задача» под списком.
- **Календарь-месяц** (по умолчанию): крупная сетка, точки состояния дня (в планах / выполнено / частично / не выполнено / важное / дневник), выбор дня показывает его задачи, с которыми можно работать прямо там. Годовой вид сохранён во вкладке «Год»; нажатие на день в году открывает этот месяц.

### Изменено
- Задачи показываются внутри общей карточки с разделителями (во всех разделах).
- Отметка «выполнено» — синяя, как в референсе; переключатели (Месяц/Год, Неделя/Месяц/Год) — с синей активной кнопкой; градиент у полосы прогресса.

### Технически
- Новое поле задачи `time` (`"HH:MM"` или пустая строка). Старые задачи работают без изменений. При переносе задачи время сохраняется.

## [0.2.0] — 2026-10-31
### Изменено
- Новый дизайн **Midnight Blue**: тёмная тема по умолчанию (`#111318`, `#1D2532`, акцент `#80A7FF`), светлая тема перекрашена в ту же гамму.
- Название приложения — **LockedLife**.
- Нижняя панель: Сегодня · Календарь · Месяц · Дневник · **Ещё**. «Статистика» и «Настройки» перенесены в «Ещё».
- Полупрозрачная нижняя панель с размытием, лёгкая анимация нажатия кнопок.
- Кнопка «Назад» Telegram возвращает из раздела «Статистика» в «Ещё».

### Технически
- Однократная миграция: при первом запуске новой версии тема переключается на тёмную (флаг `designV` в настройках).
- Название базы IndexedDB (`tg-planner`) не менялось — все данные сохраняются.
