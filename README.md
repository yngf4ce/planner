# LockedLife

Персональная система управления повседневной жизнью в виде **Telegram Mini App**
(веб‑приложение, открывающееся внутри Telegram) и ИИ‑ассистента **Noctis AI** в Telegram‑боте.

> Статус: ранняя версия. Работает модуль «Ежедневник» (задачи, календарь, статистика, дневник).
> Данные пока хранятся только на устройстве. План развития — в [ROADMAP.md](ROADMAP.md).

## Что уже умеет приложение

| Раздел | Возможности |
|---|---|
| Сегодня | Задачи на день, быстрое добавление, «важное» (звёздочка), фото, описание, перенос на другой день, прогресс дня, подсказки частых задач |
| Календарь | Годовой обзор: цвет дня показывает, всё ли выполнено |
| Месяц | Сейчас это «ближайшие 30 дней»: просроченное, важное, планы по дням (будет переделано в «Цели месяца») |
| Статистика | Неделя / месяц / год: выполнено, отложено, не выполнено, серия дней, топ задач |
| Дневник | Запись за день, настроение, поиск по записям |
| Настройки | Тема (как в Telegram / светлая / тёмная), резервная копия в файл и восстановление, удаление данных |

## Как устроен проект

Сейчас весь проект — **один файл `index.html`** (HTML + CSS + JavaScript без сборки и без `npm`).
Подробно — в [ARCHITECTURE.md](ARCHITECTURE.md).

```
planner/
├── index.html        ← всё приложение
├── README.md         ← этот файл
├── ARCHITECTURE.md   ← устройство приложения
├── ROADMAP.md        ← план развития
├── CHANGELOG.md      ← история изменений
├── SETUP_GUIDE.md    ← пошаговая настройка для новичка
└── .env.example      ← список секретных переменных (без значений)
```

## Как запустить

**На компьютере для проверки:** просто откройте `index.html` в браузере (двойной клик).
Приложение заработает, но без функций Telegram (вибрация, кнопка «Назад»).

**В Telegram:** файл нужно разместить на хостинге с HTTPS (GitHub Pages или Cloudflare Pages)
и указать его адрес у бота в @BotFather. Пошагово — в [SETUP_GUIDE.md](SETUP_GUIDE.md).

## Безопасность

- Никогда не добавляйте в репозиторий файлы `.env` и любые токены/ключи.
- Все секреты хранятся только в настройках хостинга / Supabase / GitHub Secrets.
