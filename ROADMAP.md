# План развития LockedLife

Каждый этап — небольшой и проверяемый. Следующий начинается после подтверждения, что предыдущий работает.

## Этап 1. Новый дизайн и навигация (только фронтенд, без сервера)

- [x] Переименование в LockedLife

## Этап 2. «Месяц»: цели и повторяющиеся задачи (локально)
- Цели месяца: добавить / изменить / удалить / отметить, процент, переключение месяцев
- Правила повторения: каждый день / дни недели, дата начала и конца, пауза
- Отметка выполнения отдельно для каждого дня, без копий задач

## Этап 3. Сервер: Supabase
- Проект Supabase, таблицы, RLS
- Edge Function `api` с проверкой `initData` и белым списком Telegram ID
- Синхронизация задач/дневника/целей, перенос локальных данных
- Фото — в приватный Storage

## Этап 4. «Финансы»
- Балансы, операции (расход/доход/перевод), категории с иконкой и цветом, архив
- История и фильтры, статистика, месячные бюджеты, EUR/USD/UAH
- Защита от двойного списания (idempotency key)

## Этап 5. «Идеи»
- Список идей с категориями, поиск; поле для расшифровки голосовых

## Этап 6. Noctis AI — бот
- Webhook → Edge Function `bot` с секретом и дедупликацией
- Текст → разбор LLM в JSON‑команды → валидация → действие
- Голос → Groq Whisper → текст (расшифровка сохраняется)
- Подтверждение кнопками для финансов, удаления и массовых изменений
- Вопросы‑отчёты («сколько я потратил за неделю?») — считаются кодом, не моделью

## Этап 7. Дальше
- Здоровье (тренировки, питание), общая аналитика, настройка главной панели
- Экспорт и удаление всех данных пользователя на сервере
- Открытие доступа другим пользователям
